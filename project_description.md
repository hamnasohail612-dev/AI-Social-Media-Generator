# Project Documentation

## 1. Project Title
Serverless AI Content Assistant

## 2. Problem Statement
Small business owners and students spend hours trying to write engaging social media captions, leading to inconsistent posting schedules.

## 3. Solution Overview
This project leverages Google's Gemini 1.5 Flash LLM through custom System Instructions. By structuring specific prompt guidelines, the AI acts as a dedicated marketing manager, outputting platform-ready copy instantly without requiring any backend programming code.
