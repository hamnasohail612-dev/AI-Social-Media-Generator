# 🚀 AI-Powered Social Media Content Engine

A no-code, prompt-engineered Generative AI assistant built using Google Gemini 1.5 Flash via Google AI Studio.

## ✨ Features
- **Persona-Driven:** Acts as a professional digital marketing executive.
- **Multi-Platform Support:** Tailors copy lengths and tones for LinkedIn, Instagram, and X.
- **Zero Code:** Relies entirely on optimized System Instructions and advanced Prompt Engineering.

## 🛠️ How to Replicate
1. Go to [Google AI Studio](https://google.com).
2. Select the **Gemini 1.5 Flash** model.
3. Paste the following text into the **System Instructions** box:
   "You are an expert social media manager. When the user gives you a topic and a platform, you must write a highly engaging post with hashtags and emojis."
4. Input your topic in the chat box and click **Run**.
